# Local site configuration

Keep site inventory, instructions, findings and secrets in this ignored directory.
Only this README and `websec.local.example.json` are public examples.
Copy the example to `websec.local.json` and replace its placeholders before running the [web security checker](../agentmail/WEBSEC.md).
Never put real hostnames, mail addresses, credentials or private policy into the example.
