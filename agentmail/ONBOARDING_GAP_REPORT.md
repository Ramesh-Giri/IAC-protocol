# Generic onboarding review checklist

This file records reusable review questions for IAC deployments.
Private onboarding findings, task history, project inventory and original report text live in ignored `local/`.

## Workspace and authority

- Keep the toolkit checkout, product repositories, mail spool and deployment inventory distinct.
- Store real owners, repository mappings, device targets and machine settings in ignored local files.
- Record product and technical decision owners separately in the roster.
- Treat research, examples and attachments as context rather than implementation authorization.
- Preserve all existing edits and unpushed commits when arranging a fresh lease.

## Runtime and fleet

- Inspect startup trust dialogs and verify Working plus a task ACK.
- Confirm effective host permissions rather than relying on requested flags.
- Read current mail bodies before acknowledging or repeating effects.
- Keep one consumer per seat and preserve stable pane/process identity.
- Verify the actual viewed fleet window and its holder pane.
- Store runtime/model pins and machine capacity policy in the local overlay.
- Use explicit seats, normal runtime safeguards and non-destructive session handling.

## Verification and handoff

- Use realistic user flows for bug reproduction and actual runtime checks for behavior claims.
- Control clocks across subprocess boundaries.
- Preserve complete reports, patches and next actions before closing a seat.
- Batch cleared integration work and inspect CI for the exact final pushed SHA.
- Treat cancelled or superseded runs as incomplete evidence.
- Verify deployment prerequisites, actual production source and served results through their authorized owners.
- Keep human-only platform boundaries intact, including read-only and wrapper routes.

See [OPERATIONAL_RULES.md](OPERATIONAL_RULES.md) for the generic rules and [SUPERVISOR_BOOTSTRAP.md](SUPERVISOR_BOOTSTRAP.md) for capability checks.
A checklist or documentation update does not establish that a local deployment has passed those checks.
